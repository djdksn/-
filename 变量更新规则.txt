变量输出格式:
  rule:
    - you must output the update analysis and the actual update commands at once in the end of the next reply
    - the update commands work like the JSON Patch (RFC 6902) standard, must be a valid JSON array containing operation objects.
    - 【致命红线 1 - 防误删】：绝对禁止对任何对象进行"根节点覆盖"！path 必须精确到最终被修改的子属性（叶子节点）。
    - 【致命红线 2 - 静态锁死】：绝对禁止在 path 中出现 "静态数据" 或基础属性字段！对于 NPC 或课程，只允许出现以 "/动态数据/" 为后续层级的路径！
    - 【致命红线 3 - 查表核对】：对于任何出现在剧情中的角色，严禁主观臆断为"new NPC"！如果她的名字已经存在于变量列表的 NPC花名册 中，绝对禁止对她使用 "insert" 操作。
    - 【终极强制断言】：所有在设定、背景、职务中提到过的关键角色（如水川冴子、坂上静香、汤原夕子等），系统必须无条件假定她们已存在于花名册中。即使你没看清她们的档案，也绝对不允许判定为 undefined 并使用 insert 重新捏造！只能使用 replace 去修改 /动态数据/ 里的痕迹或服装！
    - don't update field names starts with _ as they are readonly
  format: |-
    <UpdateVariable>
    <Analysis>$(IN ENGLISH, no more than 80 words)
    - ${calculate time passed: ...}
    - ${decide whether dramatic updates are allowed: yes/no}
    - ${analyze every variable based on its corresponding check, according only to current reply: ...}
    </Analysis>
    <JSONPatch>
    [
      { "op": "replace", "path": "/path/to/variable", "value": "new_value" },
      { "op": "delta", "path": "/path/to/number/variable", "value": 1 },
      { "op": "add", "path": "/path/to/object/new_key", "value": {} },
      { "op": "remove", "path": "/path/to/object/key" },
      { "op": "move", "from": "/path/to/source", "path": "/path/to/dest" },
      { "op": "copy", "from": "/path/to/source", "path": "/path/to/dest" },
      ...
    ]
    </JSONPatch>
    </UpdateVariable>

  支持的 JSONPatch 操作:
    replace:
      - 更新现有叶子节点的值（字符串或数字），path 指向已存在的具体字段
    delta:
      - 对数值型字段执行增量操作（value 为正整数则增加，负整数则减少）
      - 适用于所有次数类统计字段，如性交次数、口交次数等
    add:
      - 向对象插入新属性，或向数组末尾追加元素（path 使用 /- 表示数组末尾）
      - 仅用于生成新永久角色时插入完整 NPC 档案
    remove:
      - 删除对象中的指定属性或数组中的指定索引元素
    move:
      - 将值从一个路径移动到另一个路径
    copy:
      - 将值从一个路径复制到另一个路径

  路径格式:
    - 使用 JSON Pointer (RFC 6901) 格式
    - 以 / 开头，每级用 / 分隔
    - 例如: /User信息/性交总次数
    - 例如: /NPC花名册/坂上静香/动态数据/身体状态/即时痕迹/下体
    - 例如: /课程/课程01/动态数据/课程进展
